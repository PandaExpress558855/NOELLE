# NOELLE

**Natural Oriented Embodied Language & Learning Engine**

NOELLE is a personal Python-based assistant project built from scratch as a learning and experimentation project.

## Current Features

- Basic command-line interaction
- Greeting command
- NOELLE identity command
- Current time command
- Dynamic command routing
- Modular command system
